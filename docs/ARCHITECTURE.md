# 技术实现

本文说明「键鼠工厂」内部是怎么实现的：钩子、注入、调度、录制回放与界面。面向想了解原理或参与开发的读者；使用方式见 [README](../README.md)，功能方案的推演与落地记录见 [PLAN](PLAN.md)。

## 平台与整体思路

Windows x64，C# / .NET 8 WinForms。核心是一条「低级钩子采集 → 工作线程按时间轴调度 → `SendInput` 注入」的链路，连按、鼠标连点、轨迹回放三条业务共用这套底座，UI 只负责收集参数、开关引擎、轮询状态，不参与实时调度。

## 各模块实现

- **键盘钩子**：`SetWindowsHookEx(WH_KEYBOARD_LL)` 低级钩子，过滤自身注入事件防止自我触发。
- **防打字干扰**：`TypingGuard` 纯状态机，不单独装钩子，由连发引擎把过滤后的物理按键转发进来。两个暂停来源：① 焦点检测用 `GetForegroundWindow` + `GetWindowThreadProcessId` 比对进程 PID（比窗口句柄稳——游戏弹子窗口、切输入法时 HWND 会变而进程不变），开启时懒锁定游戏进程，焦点离开即暂停、切回自动复位；② 聊天键按下切打字态，游戏自绘聊天框系统认不出输入框，只能认按键。暂停时工作线程抬起所有模拟按下的键并停止注入，钩子回调放行物理键（模式 B 也不吞）、不触发连按；聊天键本身放行给游戏，否则聊天框打不开。前台查询实时做，打字第一下就能判出来，不依赖工作线程轮询。
- **鼠标钩子**：`SetWindowsHookEx(WH_MOUSE_LL)` 低级钩子（`LLMHF_INJECTED` 过滤自身注入的点击），触发时拦截原生点击由引擎统一注入。
- **按键模拟**：`SendInput` 扫描码方式发送（键盘）/ `MOUSEEVENTF_*` 标志（鼠标），兼容性最好。
- **连按 / 连点调度**：工作线程按 `Stopwatch` 维护每个目标的「下次到期时刻」，用完就阻塞在 `AutoResetEvent` 上——没人按键时零唤醒（实测 525 次/秒 → 0），按键/松手/停止时立即叫醒（唤醒延迟 ~0.03ms，比 1ms 轮询的 ~1ms 更快）；`timeBeginPeriod(1)` 也只在真有键要连按时申请，空闲时把系统计时精度还回去。
- **轨迹录制**：`WH_MOUSE_LL` 回调里只做「过滤 + 预分配列表 Add」，不写文件、不碰 UI，避免回调超时被系统静默摘钩；悬浮条矩形整块排除、两级时间/位移降噪。
- **轨迹回放**：独立高精度线程按录制时间轴重放；定位用 `MOUSEEVENTF_ABSOLUTE | VIRTUALDESK` 归一化到虚拟桌面，多屏负坐标与 125%/150% 缩放都和录制一致；相邻移动间隔 ≥32ms 且位移 ≥4px 时按 16ms 补点，点击按下/抬起至少保持 20ms；回放速度由 `PlaybackSpeed`（1.00–5.00，0.25 档）统一缩放——把时间轴到位时刻与轮间隔同除以倍速，而按下保持的 20ms 与「固定时长」的墙钟分钟数不缩放（玩家要放 N 分钟就是 N 分钟）。回放状态条挂 `WS_EX_TRANSPARENT | WS_EX_NOACTIVATE`，只显示不接鼠标，轨迹点过去也不会被它吞掉。等待同样不用轮询：线程睡到时间轴下一个点的到期时刻，轮与轮之间连 1ms 计时精度也还回去、最后 50ms 再提回来定点（实测间隔期唤醒约 700 次/秒 → 约 150 次/秒，剩余部分是回放状态条自身刷新），停止时立即叫醒。尾段采用 10ms 小步等待而不是一次等到底——系统调度偶尔会把单次长等待推迟几十毫秒，小步每醒一次重算剩余可立即补偿（实测最大迟到 38ms → 2ms）；10 轮总时长 13008ms → 13011ms 无漂移。
- **全局热键**：`RegisterHotKey` + `WM_HOTKEY` 消息。四个主按钮的文案由热键动态拼出（如「开始录制 · F9」），热键改动或被占用自动调整后统一走 `RefreshRunCard` / `SyncRecordButtons` 重刷。
- **自绘 UI**：全部控件（按钮、输入框、数字框、下拉框、复选框、滚动条、托盘）基于 GDI+ 手写。
- **运行浮窗**：录制、回放、连按、连点四类运行态各有一条右下角浮条。录制条可拖动且带停止按钮（并标出停止热键）；回放 / 连按 / 连点三条只读且鼠标穿透（`WS_EX_TRANSPARENT | WS_EX_NOACTIVATE`）——它们显示时游戏正在接收注入的输入，浮条若可点击会吞掉一次点击或误触自身按钮。连按/连点浮窗不单独记引擎类型，按 `_mouseEngine.Running` 选热键文案。
- **录制页滚动**：`WheelFilter`（全局 `IMessageFilter`）只接管录制页列表的滚轮，按 30px 行高换算步进；按键页因内容高度恒 ≤ 视口高度，没有滚动条。拖动 `FlatScrollBar` 时内容容器约 40 个自绘子控件需整体位移，故把位移节流到 ~60fps 并在松手时按最终坐标补位——卡顿来自子控件重排而非滚动条自身绘制。

## 设计取舍

- **管理员权限（UIPI）**：程序强制以管理员运行并弹 UAC。游戏被反作弊保护以高权限运行时，Windows UIPI 会丢弃低权限进程注入的按键，只有管理员运行注入才能到达游戏；注入被系统拦截时，状态栏与 `error.log` 会给出提示。
- **键位范围只保留「游戏技能键」**：`A-Z`、`0-9`、空格、符号键与小键盘 `N0`–`N9`，其余一律不支持——
  - **F 键让给全局热键**：四个热键占用 `F1`–`F12`，目标键若也能选 F 键，按下去只会被系统截走当热键用，连按收不到那次按下；
  - **方向键与编辑键**（`TAB`/`ENT`/`ESC`/`BS`/`HOME`/`END`/`PGUP`/`PGDN`/`Delete`/`Insert`）在游戏里没有连按价值，留着反而会把文本框的光标移动、退格删除、Tab 切换焦点一并吃掉；
  - **修饰键**（`Shift`/`Ctrl`/`Alt`）连按没有意义，而「拦截原生」模式会把系统修饰键一起拦掉，大写与组合键全部失效；
  - `Delete` 在键名框里用于清空当前行键名，因此不作为目标键。
- **连按间隔 50–5000ms（约 20 次/秒）**：游戏按帧（60fps≈16.7ms）轮询键盘状态、以「上帧未按下→本帧按下」的边沿触发攻击，按下/抬起窗口短于 1 帧会被整段错过。因此引擎强制「按下保持 ≥20ms、抬起 ≥20ms」，20 次/秒已接近 60 帧游戏边沿检测的物理极限，并非工具限制。
- **回放停止补键**：回放停止（按钮或热键）立即生效，并补发所有处于按下状态的鼠标键，不会卡键。
- **分辨率变更提示**：坐标按虚拟桌面归一化注入（见上文轨迹回放），但录制后更换过分辨率时，回放前会提示轨迹可能有偏移。
